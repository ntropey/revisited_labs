## Full Description
Logisim Revisited is a modern rebirth of Carl Burch's classic Logisim 2.7.1 digital logic simulator for the modern web — no Java required. Simulate circuits with a 4-state engine (0, 1, floating Z, and error E) across multi-bit buses up to 32 bits, using the classic component libraries: gates, plexers, arithmetic, memory, and I/O.

Open standard Logisim .circ files, or export your own. Verify logic with interactive 2–4 variable Karnaugh maps, Quine-McCluskey minimization, and one-click schematic synthesis from truth tables.

Debug like a pro: click any wire or pin to trace signal propagation backward, or let the 4-stage Socratic Circuit Coach walk you through circuit debugging and K-map grouping.

A tribute to the original: the complete classic component set, rebuilt and extended with modern tooling.

100% free and open source (GPL-3.0-or-later). No accounts, no cloud, no tracking — your circuits live on your device. Works offline, on any device.

## Key Features
1. Simulate circuits with a 4-state engine — 0, 1, floating Z, and error E.

3. Import and export standard Logisim 2.7.1 .circ files directly.
4. Analyze truth tables with 2–4 variable Karnaugh maps and Quine-McCluskey synthesis.
5. Debug any wire with the backward Signal Prover or the 4-stage Socratic Circuit Coach.
6. Solve Daily Logic Challenges — offline, private, no account required.
